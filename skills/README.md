# Skills

Her alt klasör bir video türü için bir skill'dir.

| Klasör | Açıklama |
|--------|----------|
| [sinematik-reklam](sinematik-reklam/) | Sorularla netleştirilen, kodla üretilen sinematik kısa reklamlar |

## Bir skill'in yapısı

```
skill-adi/
  SKILL.md        ← Ana talimatlar: sorular, plan, üretim adımları
  referanslar/    ← Ayrıntılı rehberler (gerektiğinde okunur)
  scripts/        ← Yeniden kullanılabilir kod
  ornekler/       ← Çalışan örnek projeler
```
